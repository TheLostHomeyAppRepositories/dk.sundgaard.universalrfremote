Управляйте пультами 433 МГц, которые Homey не может выучить сам, например от маркиз, рулонных штор, розеток, дверных звонков и ворот.
Universal RF Remote добавляет в Homey пульт с вашими собственными кнопками, например Втянуть, Стоп и Выдвинуть.
Их можно нажимать в приложении Homey и использовать в потоках.

Каждая кнопка получает код из записи Flipper Zero (файл .sub) или из значений, которые вы вводите сами.
Каждую кнопку можно проверить перед завершением настройки.

Приложение поддерживает 32 протокола пультов с фиксированным кодом.
Среди них Princeton, который используется во многих розетках и звонках, и CAME, который используется во многих приводах ворот.
Пульты, которые меняют код при каждом нажатии, скопировать нельзя.
Это, например, маркизы Somfy, автомобильные ключи и многие современные гаражные ворота.
