Steuere die 433-MHz-Fernbedienungen, die Homey nicht selbst lernen kann, etwa für Markisen, Jalousien, Steckdosen und Tore.
Füge eine Fernbedienung mit eigenen Tasten hinzu und gib jeder Taste ihren Code, indem Homey der Fernbedienung zuhört, aus einer Flipper-Zero-Aufnahme oder per Eingabe.

Gib den Tasten eine Funktion wie Hoch, Stopp und Runter oder Ein und Aus, dann bekommt das Gerät Homeys eigene Steuerung, funktioniert mit Sprachassistenten und kann eine Markise auf eine Position fahren.
Fernbedienungen, die bei jedem Druck ihren Code wechseln, etwa Somfy, können nicht kopiert werden.
