Many 433 MHz remotes for awnings, blinds, sockets, doorbells and gates are hard to teach to Homey. Universal RF Remote takes another route: read the remote with a Flipper Zero and give Homey the exact code. Create a remote control device, add as many buttons as you like, give each one its own label such as In, Out or Stop, and load the .sub file the Flipper saved for that button. You can also type in the protocol, key, bit count, TE and frequency exactly as the Flipper shows them. Every button can be tested before the device is created, and the buttons can be pressed from the device, used in flows and controlled by voice assistants.

The app rebuilds each signal from the decoded values, the same way the Flipper does, and supports 32 fixed-code protocols such as Princeton, CAME, Nice FLO, Holtek and Dooya, as well as RAW and BinRAW recordings. Homey Pro can transmit between 433.00 and 433.99 MHz. Remotes with rolling codes, such as KeeLoq or Somfy RTS, cannot be copied, and the app tells you so. Universal RF Remote is an independent, open source app and is not affiliated with Flipper Devices.
