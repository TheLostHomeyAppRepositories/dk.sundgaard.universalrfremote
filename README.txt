Control the 433 MHz remotes Homey can't learn on its own, such as the ones for awnings, blinds, sockets, doorbells and gates.
Universal RF Remote adds a remote to Homey with your own buttons, like In, Stop and Out.
You can tap them in the Homey app and use them in flows.

Each button gets its code from a Flipper Zero recording (.sub file) or from values you type in.
You can test every button before you finish.

The app supports 32 remote protocols with a fixed code.
These include Princeton, used in many sockets and doorbells, and CAME, used in many gate openers.
Remotes that change their code on every press can't be copied.
These include Somfy awnings, car keys and many newer garage doors.
