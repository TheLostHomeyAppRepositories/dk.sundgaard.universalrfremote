Does your awning, blind, socket, doorbell or gate use a 433 MHz remote that Homey cannot learn reliably? Universal RF Remote lets Homey send exactly the code your remote sends. You get one remote control device with your own buttons, such as In, Stop and Out, that you can tap in the Homey app and use in flows. Each button gets its code from a small .sub file, the format a Flipper Zero saves when it reads a remote, and you can test every button before you finish. Large community collections of .sub files for common remotes can be downloaded for free on GitHub, and if you know the code values, you can also type them in.

Try Homey's own 433 MHz learning first; this app is for the remotes it cannot learn. Most simple remotes with a fixed code work, including many sockets, awnings, blinds and gate openers. Remotes that change their code on every press for security, such as Somfy awnings, car keys and many newer garage doors, cannot be copied, and the app tells you so. Homey Pro sends on 433 MHz only, not 868 MHz. Universal RF Remote is an independent, open source app and is not affiliated with Flipper Devices.
