Does your awning, blind, socket, doorbell or gate use a 433 MHz remote that Homey cannot learn? Universal RF Remote lets Homey send exactly the code your remote sends. You create a remote control device with your own buttons, such as In, Stop and Out, which you can tap in the Homey app and use in flows. Each button gets its code from a .sub file, the format a Flipper Zero saves when it reads a remote, or from values you type in, and you can test every button before you finish. Most simple remotes with a fixed code work, including many sockets, awnings, blinds, doorbells and gate openers. Remotes that change their code on every press for security, such as Somfy awnings, car keys and many newer garage doors, cannot be copied, and the app tells you so. Homey Pro sends on 433 MHz only, not 868 MHz. Try Homey's own 433 MHz learning first; this app is for the remotes it cannot learn. Universal RF Remote is an independent, open source app and is not affiliated with Flipper Devices.

How to get started: on the Flipper Zero, open Sub-GHz and choose Read (the default 433.92 MHz suits most remotes; other frequencies are set under Config). Hold the remote close and press the button. The Flipper shows the protocol and bit count, for example Princeton 24bit, followed by the key, the TE in µs and, at the top, the frequency. Choose Save and name the file after the button, and repeat for each button. A Flipper Zero is a great help here, because it decodes the remote for you and lets you test the signal: open the saved file under Sub-GHz, Saved and choose Emulate, and if the device reacts, the code is right. Later you can hold the Flipper near Homey in Read mode while you press Test in the app, to check that Homey sends the same code. If the Flipper does not recognise the remote, use Read RAW and save the recording instead. To get the files onto your phone, open the Flipper mobile app, connect over Bluetooth, find the file in the archive and share it to your files, or copy it from the subghz folder on the SD card with qFlipper on a computer. You can also skip the file and just note the protocol, key, bits, TE and frequency from the screen; saved codes can be viewed again under Sub-GHz, Saved. Without a Flipper, community collections on GitHub, such as the UberGuidoZ Flipper repository, have thousands of .sub files sorted by device type and brand: open a file, choose Raw and copy all the text. A downloaded code only works if your receiver uses it, but many receivers that learn codes accept it if you put the receiver in learning mode and press Test. In Homey, go to Devices, tap +, choose Universal RF Remote and Remote control, pick a name and an icon and tap Add button for each button. Give the button a label, then either choose the file under .sub file, paste the file contents into the box below it, or choose Enter, pick the protocol, type the key (0x5A3C91 and 00 00 00 00 00 5A 3C 91 both work), bits, TE and frequency and tap Use these values. Tap Test to check each button and finish with Add device. Buttons and codes can be changed later with Repair device.
