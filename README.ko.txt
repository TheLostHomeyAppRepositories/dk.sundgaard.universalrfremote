Homey가 스스로 학습할 수 없는 433 MHz 리모컨을 제어하세요. 예를 들어 차양, 블라인드, 콘센트, 게이트용 리모컨입니다.
나만의 버튼으로 리모컨을 추가하고, Homey가 리모컨 신호를 듣게 하거나 Flipper Zero 녹화 파일 또는 직접 입력으로 각 버튼의 코드를 지정하세요.

버튼에 위로, 정지, 아래로 또는 켜기, 끄기 같은 기능을 지정하면 기기에 Homey 기본 컨트롤이 생기고, 음성 비서로 제어할 수 있으며 차양을 원하는 위치로 움직일 수 있습니다.
Homey는 실제 리모컨 신호를 듣고 버튼을 누르면 플로우를 실행할 수도 있지만, Somfy처럼 누를 때마다 코드가 바뀌는 리모컨은 복사할 수 없습니다.
