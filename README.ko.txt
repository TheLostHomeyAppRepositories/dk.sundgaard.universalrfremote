어닝, 블라인드, 콘센트, 초인종, 대문처럼 Homey가 스스로 학습하지 못하는 433 MHz 리모컨을 제어하세요.
Universal RF Remote는 접기, 정지, 펴기처럼 원하는 버튼이 있는 리모컨을 Homey에 추가합니다.
Homey 앱에서 버튼을 누르고 플로우에서 사용할 수 있습니다.

각 버튼의 코드는 Homey가 리모컨 신호를 직접 듣거나, Flipper Zero 녹화 파일(.sub 파일)이나 직접 입력한 값에서 가져옵니다.
설정을 마치기 전에 모든 버튼을 테스트할 수 있습니다.

이 앱은 고정 코드를 쓰는 리모컨 프로토콜 32개를 지원합니다.
여기에는 많은 콘센트와 초인종에 쓰이는 Princeton, 많은 대문 개폐기에 쓰이는 CAME가 포함됩니다.
누를 때마다 코드가 바뀌는 리모컨은 복사할 수 없습니다.
Somfy 어닝, 자동차 키, 많은 최신 차고 문이 여기에 해당합니다.
