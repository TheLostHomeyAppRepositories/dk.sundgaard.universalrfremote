어닝, 블라인드, 콘센트, 초인종이나 대문에 Homey가 학습하지 못하는 433 MHz 리모컨을 쓰고 계신가요? Universal RF Remote를 사용하면 Homey가 리모컨과 똑같은 코드를 보냅니다. 접기, 정지, 펴기처럼 원하는 버튼으로 리모컨을 만들어 Homey 앱에서 누르고 플로우에서 사용할 수 있습니다. 각 버튼의 코드는 Flipper Zero가 리모컨을 읽을 때 저장하는 .sub 파일에서 가져오거나 직접 값을 입력할 수 있으며, 설정을 마치기 전에 모든 버튼을 테스트할 수 있습니다. 많은 콘센트, 어닝, 블라인드, 초인종, 대문 개폐기 등 고정 코드를 쓰는 대부분의 간단한 리모컨이 작동합니다. Somfy 어닝, 자동차 키, 많은 최신 차고 문처럼 보안을 위해 누를 때마다 코드가 바뀌는 리모컨은 복제할 수 없으며, 앱이 이를 알려 줍니다. Homey Pro는 433 MHz에서만 송신하며 868 MHz는 지원하지 않습니다. 먼저 Homey 자체의 433 MHz 학습 기능을 사용해 보세요. 이 앱은 Homey가 학습하지 못하는 리모컨을 위한 것입니다. Universal RF Remote는 독립적인 오픈 소스 앱이며 Flipper Devices와 관련이 없습니다.

시작하는 방법: Flipper Zero에서 Sub-GHz를 열고 Read를 선택합니다(기본값 433.92 MHz는 대부분의 리모컨에 맞으며, 다른 주파수는 Config에서 설정합니다). 리모컨을 가까이 대고 버튼을 누릅니다. Flipper에 Princeton 24bit처럼 프로토콜과 비트 수가 표시되고, 이어서 키(Key), µs 단위의 TE, 화면 위쪽에 주파수가 표시됩니다. Save를 선택해 버튼 이름으로 파일을 저장하고 버튼마다 반복합니다. Flipper Zero는 리모컨을 대신 해독해 주고 신호를 테스트할 수 있게 해 주므로 큰 도움이 됩니다. Sub-GHz, Saved에서 저장한 파일을 열고 Emulate를 선택했을 때 기기가 반응하면 코드가 맞는 것입니다. 나중에 앱에서 테스트를 누르는 동안 Read 모드의 Flipper를 Homey 가까이에 두면 Homey가 같은 코드를 보내는지 확인할 수 있습니다. Flipper가 리모컨을 인식하지 못하면 Read RAW를 사용해 녹음을 저장하세요. 파일을 휴대폰으로 옮기려면 Flipper 모바일 앱에서 블루투스로 연결하고 보관함에서 파일을 찾아 내 파일로 공유하거나, 컴퓨터의 qFlipper로 SD 카드의 subghz 폴더에서 복사하세요. 파일 없이 화면에 표시된 프로토콜, 키, 비트, TE, 주파수만 적어 두어도 됩니다. 저장된 코드는 Sub-GHz, Saved에서 다시 볼 수 있습니다. Flipper가 없다면 UberGuidoZ의 Flipper 저장소 같은 GitHub 커뮤니티 모음에서 기기 유형과 브랜드별로 정리된 수천 개의 .sub 파일을 찾을 수 있습니다. 파일을 열고 Raw를 선택한 뒤 모든 텍스트를 복사하세요. 내려받은 코드는 수신기가 그 코드를 쓸 때만 작동하지만, 코드를 학습하는 많은 수신기는 학습 모드로 전환한 뒤 테스트를 누르면 그 코드를 받아들입니다. Homey에서 기기로 이동해 +를 누르고 Universal RF Remote와 리모컨을 선택한 뒤 이름과 아이콘을 고르고 버튼마다 버튼 추가를 누릅니다. 버튼에 라벨을 붙인 다음 .sub 파일 탭에서 파일을 선택하거나, 아래 상자에 파일 내용을 붙여넣거나, 직접 입력을 선택해 프로토콜을 고르고 키(0x5A3C91과 00 00 00 00 00 5A 3C 91 모두 가능), 비트, TE, 주파수를 입력한 뒤 이 값 사용을 누릅니다. 테스트를 눌러 각 버튼을 확인하고 기기 추가로 마칩니다. 버튼과 코드는 나중에 기기 복구에서 변경할 수 있습니다.
