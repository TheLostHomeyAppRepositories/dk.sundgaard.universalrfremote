Votre store banne, votre store, votre prise, votre sonnette ou votre portail utilise une télécommande 433 MHz que Homey ne sait pas apprendre ? Avec Universal RF Remote, Homey envoie exactement le code de votre télécommande. Vous créez une télécommande avec vos propres boutons, comme Rentrer, Stop et Sortir, que vous pouvez toucher dans l'application Homey et utiliser dans vos flows. Chaque bouton reçoit son code d'un fichier .sub, le format qu'enregistre un Flipper Zero lorsqu'il lit une télécommande, ou de valeurs que vous saisissez, et vous pouvez tester chaque bouton avant de terminer. La plupart des télécommandes simples à code fixe fonctionnent, dont de nombreuses prises, stores bannes, stores, sonnettes et ouvre-portails. Les télécommandes qui changent de code à chaque appui pour des raisons de sécurité, comme les stores Somfy, les clés de voiture et de nombreuses portes de garage récentes, ne peuvent pas être copiées, et l'application vous le signale. Homey Pro émet uniquement en 433 MHz, pas en 868 MHz. Essayez d'abord l'apprentissage 433 MHz intégré de Homey ; cette application est faite pour les télécommandes qu'il ne sait pas apprendre. Universal RF Remote est une application indépendante et open source, sans lien avec Flipper Devices.

Pour commencer : sur le Flipper Zero, ouvrez Sub-GHz et choisissez Read (la valeur par défaut de 433,92 MHz convient à la plupart des télécommandes ; les autres fréquences se règlent dans Config). Tenez la télécommande près du Flipper et appuyez sur le bouton. Le Flipper affiche le protocole et le nombre de bits, par exemple Princeton 24bit, puis la clé (Key), le TE en µs et, en haut, la fréquence. Choisissez Save, nommez le fichier d'après le bouton et recommencez pour chaque bouton. Un Flipper Zero est ici d'une grande aide, car il décode la télécommande pour vous et permet de tester le signal : ouvrez le fichier enregistré dans Sub-GHz, Saved et choisissez Emulate ; si l'appareil réagit, le code est bon. Plus tard, vous pouvez tenir le Flipper en mode Read près de Homey pendant que vous appuyez sur Tester dans l'application, pour vérifier que Homey envoie le même code. Si le Flipper ne reconnaît pas la télécommande, utilisez Read RAW et enregistrez la capture. Pour transférer les fichiers sur votre téléphone, ouvrez l'application mobile Flipper, connectez-vous en Bluetooth, trouvez le fichier dans l'archive et partagez-le vers vos fichiers, ou copiez-le depuis le dossier subghz de la carte SD avec qFlipper sur un ordinateur. Vous pouvez aussi vous passer du fichier et noter simplement le protocole, la clé, les bits, le TE et la fréquence affichés à l'écran ; les codes enregistrés restent consultables dans Sub-GHz, Saved. Sans Flipper, des collections communautaires sur GitHub, comme le dépôt Flipper d'UberGuidoZ, proposent des milliers de fichiers .sub classés par type d'appareil et par marque : ouvrez un fichier, choisissez Raw et copiez tout le texte. Un code téléchargé ne fonctionne que si votre récepteur l'utilise, mais de nombreux récepteurs qui apprennent les codes l'acceptent si vous mettez le récepteur en mode apprentissage et appuyez sur Tester. Dans Homey, allez dans Appareils, touchez +, choisissez Universal RF Remote puis Télécommande, choisissez un nom et une icône et touchez Ajouter un bouton pour chaque bouton. Donnez un libellé au bouton, puis choisissez le fichier sous Fichier .sub, collez le contenu du fichier dans la zone en dessous, ou choisissez Saisir, sélectionnez le protocole, tapez la clé (0x5A3C91 et 00 00 00 00 00 5A 3C 91 fonctionnent tous les deux), les bits, le TE et la fréquence, puis touchez Utiliser ces valeurs. Touchez Tester pour vérifier chaque bouton et terminez avec Ajouter l'appareil. Les boutons et les codes peuvent être modifiés plus tard avec Réparer l'appareil.
